# lavka-orders-dashboard

ДЗ 4 по визуализации. Дашборд по заказам клиента Лавки (датасет с 1 недели, вариант A).

Сделано на d3.js + vue 3, без сборки, просто html.

Ссылка: https://arseniibeliaev.github.io/lavka-orders-dashboard/

Что есть:
- метрики за последний месяц (заказы, траты, скидка) + сравнение с прошлым месяцем и прошлым годом
- динамика за 24 месяца
- топ товаров в штуках/рублях с картинками, в тултипе график цены
- таблица категорий, по клику фильтр
- фильтр по категориям сверху

Запуск локально:
```
python3 -m http.server
```

data.json собирается из xlsx через prepare_data.py, картинки - через prepare_images.py

отменённые заказы не учитываются
